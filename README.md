# TOP_rock_paper_scissor
TOP project for rock-paper-scissors

Results:
Used window prompt style to prompt user on the their choice. Choice is either rock, paper, or scissor complete with edge casing in case user doesn't input a valid choice. Results can then be viewed in the console logs of the browser.

Current limitations:
Results can only be viewed once all 5 round ends, and not at any point of time.
